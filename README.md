# Student Management System - Android Studio

## About the Project
Student Management System is an Android application developed using Java in Android Studio. It allows users to manage student records through a simple interface.

## Features
- Add student records
- View student records
- Edit student information
- Delete student records
- Store student data using SQLite database
- Select a major: Informatics or Information Systems

## Technologies Used
- **Language:** Java
- **IDE:** Android Studio
- **Database:** SQLite
- **Build System:** Gradle

## How to Run
1. Clone or download this repository.
2. Open Android Studio.
3. Select **Open** and choose the project folder.
4. Wait for Gradle Sync to finish.
5. Start an Android emulator or connect an Android device.
6. Click **Run** to launch the application.
